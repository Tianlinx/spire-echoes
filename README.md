## 🎮 这是什么

《尖塔回声》是一个**单文件、零依赖、点击即玩**的网页版卡牌构筑 Roguelike。打开 `index.html` 即可在浏览器里开始一场爬塔冒险——没有构建步骤，没有服务器，没有安装包。

- 四个职业：**钢铁先锋**、**暗夜游猎**、**鸡煲**、**修行者**，各自拥有专属机制：
- 钢铁先锋专属机制 **力量与护甲**：以「力量」逐层叠加攻击、「护甲」正面格挡；起始遗物「燃烧之血」战后回血，稀有牌「恶魔形态」每回合永久增长力量，正面碾压、越打越猛。新增「战地包扎 / 休整 / 再生 / 振奋 / 汲血」等回血续航手段，与「盾墙 / 碎甲击 / 战旗」等坚守增益，补齐此前缺乏续航的短板
- 暗夜游猎专属机制 **剧毒与闪避**：以「毒药瓶」起手，用毒刃与「死亡印记」持续叠加中毒腐蚀强敌，「影步」将敏捷转化为护甲，于无形中取敌性命
- 鸡煲专属机制 **储能球**：凝霜（冰盾）、蓄雷（群体伤害）、病毒（群体中毒）三类球随回合脉冲，并可用「核心过载」强化
- 修行者专属机制 **姿态流转**：平静（每回合护甲）、愤怒（攻击 ×2）、神性（攻击 ×3），于三种心境间切换攻防
- 完整的战斗、地图、商店、事件、休息、奖励流程
- 数十张卡牌、十余种敌人、多件遗物
- 拖拽出牌 + 卡牌飞向敌人的打击动画
- 重做后的经济系统：商店售价整体下调、战斗金币收益重平衡，价格与收益随层数平滑缩放，全程可负担
- 地图路径与事件选项均为「选中 → 确认」两步操作，避免误触进入战斗或选错后果
- 战斗记录以背景板形式呈现，状态图标可悬停查看说明

## ▶️ 如何运行

### 在线试玩（推荐）

**点开即玩：https://tianlinx.github.io/spire-echoes/**

本项目已开启 GitHub Pages（source = `main` 分支根目录），无需下载、无需部署，浏览器直接打开就能开始爬塔。

### 本地运行

1. 下载本仓库
2. 双击 `index.html`（或 `spire.html`）用浏览器打开
3. 开玩

## 🧱 技术栈

- 原生 HTML + CSS + JavaScript，**单文件、无框架、无外部依赖**
- Web Audio API 合成音效
- SVG 绘制连线与拖拽箭头
- 全部状态在内存中维护，支持本地存档
