## 🎮 这是什么

《尖塔回声》是一个**单文件、零依赖、点击即玩**的网页版卡牌构筑 Roguelike。打开 `index.html` 即可在浏览器里开始一场爬塔冒险——没有构建步骤，没有服务器，没有安装包。

- 四名职业，各自拥有专属机制（玩法简介 + 背景）：
  - 🦸 **钢铁先锋** —— 用「力量」越打越猛、用「护甲」正面硬扛，战后靠「燃烧之血」回血。*背景：边境要塞的最后守将，被塔收走「只要还站着就还有人在」的执念，以铁甲怒刃把守住一切的本能带进塔中。*
  - 🏹 **暗夜游猎** —— 用毒刃与「死亡印记」慢慢腐蚀强敌，用敏捷换护甲、神出鬼没。*背景：来自不存在于地图的雾港，被自己的影子追杀的她踏上塔，只为在回响里看清哪道影子才是真正的自己。*
  - 🤖 **鸡煲** —— 凝霜（冰盾）、蓄雷（群伤）、病毒（群毒）三颗储能球轮转，把敌人慢慢磨穿。*背景：残响之渊溢出的一段机械残片，没有过去也不在乎胜负，只是本能地想「把每一场战斗都跑完」。*
  - 🧘 **修行者** —— 在平静（守）、愤怒（狂攻）、神性（爆发）三种心境间切换，攻防随心。*背景：山上打坐千年证「空」的修行者，入塔是为把容纳三心境的容器，炼到再不会碎。*
- 完整的战斗、地图、商店、事件、休息、奖励流程
- 数十张卡牌、十余种敌人、多件遗物
- 拖拽出牌 + 卡牌飞向敌人的打击动画
- 重做后的经济系统：商店售价整体下调、战斗金币收益重平衡，价格与收益随层数平滑缩放，全程可负担
- 地图路径与事件选项均为「选中 → 确认」两步操作，避免误触进入战斗或选错后果
- 战斗记录以背景板形式呈现，状态图标可悬停查看说明

## 🌌 世界观

《尖塔回声》的故事发生在「残响之渊」——一个由无数崩塌时空拼凑而成的夹缝世界。当某座尖塔在一个世界崩塌，它的最后一声回响坠入此处，重新矗立为「残响之塔」，并不断召唤来自各夹缝的「回声旅人」登塔。

你正是被召唤者之一。登塔不为拯救谁，也不为某场注定的决战，只为在层层回响中，走出那条属于自己的、从未在原时空走完的路。

本作与《杀戮尖塔》原作**没有任何剧情关联**，仅借用卡牌构筑 Roguelike 的玩法框架向其致敬。
